About this data

  • Source: {{ t.source or "the Company Profile 2026" }}, shipped as a versioned file in this repository. It is a selection from the profile, not the full record. The full record is in the Knowledge Library.
  • The profile calls the assignments a selection. They are shown as selected assignments, not as the complete list of work.
  • Area groups and the one theme on each assignment are tagged by Cortech BD from the project description. They are not in the profile. Where a description names no place, the area reads n/a.
  • Outcome: Won only where a Knowledge Library record says so. Anything else reads not recorded, because an unchecked box is not a loss.
  • A past proposal joins a profile assignment only when its title matches exactly. Otherwise it is added as its own line.
  • Key partners are the nine the profile names as key partners. The data holds no ranking of partners, so none is shown.
